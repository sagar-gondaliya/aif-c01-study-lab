What you will NOT be asked to do

  • Code or invent model algorithms
  • Do data / feature engineering
  • Tune hyperparameters or do statistical proofs
  • Build pipelines or implement security protocols from scratch

You will be asked to pick the right service, pattern, metric, or risk for a business story.

How to read a question (easy method)

  1. Circle the job (translate? speech to text? stop legal advice? store embeddings?).
  2. Circle constraints: no ML team, must explain to a regulator, stay in-region, user waiting, nightly batch.
  3. Pick the managed AWS name for that job. DIY on EC2 is almost never right.
  4. If they say ensure / prevent / must not, pick a lock (Guardrails, IAM, KMS, A2I), not a polite prompt.
  5. If two answers work, pick the cheaper / lower-ops one (RAG before fine-tune, Bedrock before SageMaker).

Multiple-response: tick every correct box. Ordering and matching: one wrong pair = zero. Blank = wrong. Always guess.

How AWS writes the item

A company wants X. Which option is best?

  1. The managed AWS service that matches the job
  2. The lowest-ops option that still meets the requirement
  3. A hard control (IAM, Guardrails, encryption, A2I) over “tell the model not to”

Question types in this lab’s mocks

  • Single — one correct of four. Most items.
  • Multi — two correct of five. Miss one and the item is wrong.
  • Order — put 3–5 steps in the only correct sequence.
  • Match — pair every prompt. No partial credit.

This lab vs exam day

Each mock here is 50 scored-style questions in 90 minutes (the real exam also hides 15 extra items in the same 90 minutes). Treat 700 scaled (~70%) as the pass line. The 15 hidden items on exam day do not count — you cannot see which they are, so answer all 65.
