Decision trees

Walk these until they are automatic. Most scored items are one of these forks.

1. We have documents and want answers

  1. Need citations / private facts / changing docs → Bedrock Knowledge Bases (RAG)
  2. Employees chatting over many SaaS sources with existing permissions → Q Business / Quick
  3. Classic search without generation → Kendra
  4. Must train a custom classifier on labels → SageMaker or Comprehend custom

2. We want to change model behaviour

  1. Format / few examples → prompt / few-shot
  2. Private facts → RAG
  3. Stable style/domain with labeled pairs → fine-tune
  4. Need cheaper/faster with similar quality → distillation
  5. Brand-new FM → do not pre-train

3. Something unsafe happened

SymptomControl
Hate / sexual / violenceGuardrails content filters
Banned topic (legal/medical advice)Guardrails denied topics
Leaks SSN / emailGuardrails PII + Macie on stored data
Webpage says “ignore previous instructions”Guardrails + treat untrusted text as data
Wrong facts not in our docsGrounding + RAG
High-stakes errorA2I
Wrong team calling Claude OpusIAM / SCP
Need SOC2 PDFArtifact

4. Bedrock or SageMaker?

Managed FMs, Knowledge Bases, Guardrails, Agents → Bedrock.
Custom training, own containers, notebooks, full MLOps → SageMaker AI.

5. Q / Kiro or AgentCore?

Productised assistant you use → Amazon Q or Kiro.
Custom agents you build with tools, identity, policy → AgentCore (+ Strands if multi-agent code).
