Read this the night before. Then sleep.

#TrapCorrect reflex
1Prompt vs controlSafety/compliance → Guardrails, IAM, or A2I — not “tell the model not to”.
2Bedrock vs SageMakerNo ML team + FMs = Bedrock. Custom training = SageMaker.
3RAG vs fine-tuneChanging facts / citations = RAG. Style/format = prompt or fine-tune.
4Retrieval vs generationFix the stage that actually failed.
5Accuracy on rare eventsUse precision, recall, or F1.
6Must be exactPayroll, tax, hard rules → not an LLM.
7S3 as a vector DBOpenSearch / Aurora / Neptune / RDS / Knowledge Bases.
8MemoryDBRemoved from the 2026 in-scope list. Do not pick it.
9Q vs AgentCoreQ/Kiro = productised assistant. AgentCore = you build agents.
10Macie vs Guardrails vs ComprehendS3 at rest / model I/O / text you send.
11CloudTrail vs CloudWatch vs ArtifactAPI who-when / metrics / compliance PDFs.
12Explainability requiredTraditional ML + Clarify + Model Cards.
13Batch vs real-timeMillions overnight = batch. User waiting = real-time.
14Always guess15 items do not count and you cannot see which. Answer all 65.
15Multi-responseYou must select every correct option. Partial = zero.
