# AIF-C01 Study Lab

Local-first study site for **AWS Certified AI Practitioner (AIF-C01)**, exam guide **v1.1 (30 Apr 2026)**.

41 topic lessons, exam-style quizzes, 7 practice banks, and 5 timed mocks (65 questions · 90 minutes each). Progress stays in the browser (`localStorage`).

## Use it

- **Live:** after Vercel deploy, open the project URL
- **Local:** open `index.html` in a browser — no install

Study path: Domain 1 → every topic (read + quiz) → Domains 2–5 → flashcards / traps → quizzes → mocks 1–5.

## Rebuild topics

```bash
python3 js/_build/build.py
```
