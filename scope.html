2026 objectives — confirm you can teach these

  • Agentic AI, multi-agent, MCP, tool use, memory
  • Context engineering (window = prompt + docs + tools + history)
  • Token pricing (input + output) and prompt caching
  • Model distillation vs RAG vs fine-tune vs pre-train
  • Bedrock Prompt Management (version prompts)
  • Hallucination detection / grounding / confidence
  • AgentCore Identity and Policy
  • Q, Quick, Kiro, Strands, Nova, Transform, JumpStart, Aurora

What this exam will never ask you to do

Write training code, tune hyperparameters, design a VPC from scratch, or implement a Glue job. If a distractor is “build your own vector database on EC2,” the managed service almost always wins.
